# 0003 · Um app só para cliente e equipe

**Data:** 29/10/2026 · **Situação:** aceita

## Decisão

O app (`web/app/`) atende clientes e equipe. Depois do login, o papel da pessoa decide as abas. A antiga
"área da equipe" (`/equipe/`) agora redireciona para o app.

## Por quê

- Um código só de login, telas, componentes e instalação no celular.
- A equipe também usa no celular; no computador o menu vira lateral.
- A segurança não depende da tela: o banco recusa o que o papel não pode fazer.
