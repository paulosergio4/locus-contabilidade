# web

Tudo o que vai para o ar. O GitHub Pages publica esta pasta como está.

- Uma tecnologia por arquivo: HTML só estrutura, CSS só visual, JS só comportamento.
- Código usado por mais de uma página fica em `compartilhado/`.
- `compartilhado/vendor/` é gerado por `npm run vendor`; não edite à mão.
- Ao mudar arquivos do app, aumente `VERSAO` em `app/sw.js`.
